Prérequis

Avant de télécharger

Quel système d'exploitation est requis ?

Le launcher Lumalia est disponible pour Windows 10 et 11 (64 bits). Une version macOS/Linux pourrait arriver plus tard.

Ai-je besoin d'un compte Minecraft ?

Oui, un compte Microsoft avec Minecraft Java Edition est nécessaire pour jouer en multijoueur sur Lumalia. Le launcher vous guide pour la connexion.

Combien de RAM faut-il ?

4 Go de RAM minimum sont recommandés. Vous pouvez ajuster la quantité allouée dans les paramètres du launcher.

Le launcher se met-il à jour automatiquement ?

Oui ! Dès qu'une nouvelle version est disponible, une fenêtre s'ouvre au lancement et vous propose de mettre à jour en un clic.
